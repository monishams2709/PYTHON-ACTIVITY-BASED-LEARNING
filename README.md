## About This Repository

This repository contains 10 beginner-friendly Python programs developed
as part of the Python Programming Lab Record. The programs demonstrate
input/output operations, arithmetic calculations, conditional
statements, and loops.

## List of Programs

1.  Hospital Billing and Patient Classification
2.  University Scholarship Eligibility
3.  Employee Salary Calculation
4.  Mobile Data Plan Selection
5.  Railway Fare Calculation
6.  Shopping Bill with Discount and Tax
7.  Manufacturing Profit Target
8.  Travel Currency Budget
9.  College Event Cost and Registrations
10. Student Result with Grace Marks

## Concepts Used

-   Variables and data types
-   User input using `input()`
-   Type conversion using `int()` and `float()`
-   Arithmetic and comparison operators
-   `if`, `elif`, and `else` conditions
-   Logical operators
-   `for` loops

## How to Run

1.  Install Python 3.
2.  Download or clone this repository.
3.  Open a terminal in the folder containing the Python files.
4.  Run a program using:

``` bash
python filename.py
```

Replace `filename.py` with the actual program filename.
